# Contribuer à LughaLearn

Merci de votre intérêt ! Le projet débute et accueille les contributions utiles aux apprenants.

1. Ouvrez une **issue** décrivant le problème ou la fonctionnalité.
2. Pour les correctifs, créez une branche distincte et proposez une **pull request** claire.
3. Testez le site sur mobile et ordinateur, et vérifiez l'accessibilité au clavier.
4. Pour tout ajout linguistique, indiquez la source et sollicitez une relecture par une personne compétente en arabe standard.
5. N'ajoutez pas de données personnelles, de secrets, d'API payante obligatoire ni de contenu audio non autorisé.

## Conventions
- JavaScript natif, HTML sémantique, CSS maintenable ; zéro dépendance pour le MVP.
- Utilisez `lang="ar"` et `dir="rtl"` lorsque le texte est en arabe.
- Gardez les données pédagogiques séparables de la logique applicative lors des évolutions.
- Décrivez les étapes de test dans les pull requests.
